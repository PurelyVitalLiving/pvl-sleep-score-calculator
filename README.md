# PVL Sleep Score Calculator

A free, installable sleep assessment from Purely Vital Living that helps you understand how your daily habits may be affecting your sleep.
## About the Calculator

The PVL Sleep Score Calculator uses a short 12-question assessment to generate a personalized Sleep Score from 0 to 100.

After completing the assessment, users receive:

- A personalized Sleep Score
- A breakdown of key sleep-related habits
- Areas that may deserve attention
- Practical recommendations for improving sleep habits
- Links to additional sleep resources from Purely Vital Living

## Key Features

- Free to use
- No account required
- 12-question assessment
- Personalized 0–100 Sleep Score
- Mobile-friendly experience
- Installable Progressive Web App (PWA)
- Practical sleep recommendations
- Educational wellness resources
